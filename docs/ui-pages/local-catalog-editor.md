# 本地目录编辑页 UI 设计

本文档描述「漫集」本地目录编辑页的 UI 设计。该页面用于创建或维护用户
自己的本地目录，覆盖公共目录未收录的小众出版物或个人整理系列。本文只
描述页面自身排版和状态，不描述页面跳转。

## 页面目标

本地目录编辑页必须让用户用较低成本创建可用目录。页面需要像整理一本收藏册，
而不是填写数据库后台。

## 整体布局

页面采用“目录信息、条目生成规则、预览、保存操作”的结构。表单保持单列，
字段分组清晰。

背景使用暖纸色，输入区域使用白色或浅奶油色底，边框使用浅棕线。页面不使用
复杂多列表单。

## 顶部区域

顶部显示「新建本地目录」或当前目录名称。标题下方显示简短状态，例如
「未保存修改」「已保存」或「共 120 项」。

右侧可以放更多操作入口。删除目录必须放在二级菜单中，并配合危险确认。

## 主要内容区

目录基础信息组包含：

- 目录名称。
- 目录简称。
- 出版物类型。
- 备注。

编号规则组包含：

- 条目数量。
- 编号补零位数或编号样式。
- 封面 URL 规则。

预览组展示根据当前规则生成的前几个条目，例如第 001 期、第 002 期。预览
用于帮助用户确认编号和封面规则，不要求展示完整目录。

如果未来支持逐条维护，条目列表可以作为下方增强区域。列表项展示标题、
编号、出版日期和信息完整度，但默认不展开所有字段。

## 底部操作区

底部固定保存栏，包含主按钮「保存目录」。存在未保存修改时，按钮使用强调色。
无修改时可以显示为普通状态。

底部可以提供次级操作「预览生成结果」。删除目录不放在底部主操作区。

## 状态呈现

字段错误在字段下方就近展示，例如「目录名称不能为空」或「条目数量必须大于
0」。保存中时，保存按钮进入加载状态，避免重复提交。

保存成功后显示短反馈「已保存」。保存失败时保留所有输入，并在底部显示
「保存失败，请重试」。

## 空状态和错误状态

当预览无法生成时，预览区说明具体原因，例如「请先填写条目数量」或「封面
规则无法识别」。加载已有目录失败时，页面显示错误说明和重新加载操作。

## 移动端排版注意点

输入框采用标签在上、输入在下的单列布局。数字字段优先使用数字键盘。封面
规则字段可能较长，需要支持横向光标编辑和清晰截断。键盘弹起时，保存栏
不能遮挡当前输入字段。
