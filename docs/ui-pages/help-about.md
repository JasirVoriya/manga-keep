# 帮助与关于页 UI 设计

本文档描述「漫集」帮助与关于页的 UI 设计。该页面用于集中说明产品边界、
数据保存方式、常见问题和版本信息。本文只描述页面自身排版和状态，不描述
页面跳转。

## 页面目标

帮助与关于页必须让用户理解「漫集」能做什么、不做什么，以及自己的数据如何
保存和带走。页面应安静、可扫读，不承担营销任务。

## 整体布局

页面采用设置型分组列表。背景为暖纸色，分组使用浅色底和细线分隔。页面从
上到下为：

1. 品牌和定位。
2. 使用帮助。
3. 数据与离线说明。
4. 公共目录说明。
5. 应用边界。
6. 版本和反馈。

## 顶部区域

顶部显示标题「帮助与关于」。标题下方展示一句定位：「为实体漫画收藏而做的
本地记录工具」。

可以展示小型品牌标识、App 名称和版本号。品牌区必须克制，不占据过多首屏。

## 主要内容区

使用帮助分组包含：

- 如何标记已有。
- 如何查看缺本。
- 如何整理想要。
- 如何创建本地目录。

数据与离线分组说明本地保存、导入导出和无账号也可用。公共目录分组说明目录
来源、刷新方式和公共目录不可用时的本地可用性。

应用边界分组明确说明：

- 不提供漫画阅读。
- 不提供下载或资源搜索。
- 不内置二手交易。
- 不要求登录后才能使用。

关于分组展示版本、构建号、致谢、反馈方式和诊断信息复制入口。

## 底部操作区

页面底部显示版本号和版权信息。可提供「复制诊断信息」和「发送反馈」等次级
操作，但不放置强引导按钮。

## 状态呈现

帮助内容以静态列表为主。若支持搜索帮助，搜索框放在标题下方。搜索结果为空
时显示「没有找到相关说明」。

外部反馈入口不可用时，显示短提示，不影响用户继续浏览帮助内容。

## 空状态和错误状态

帮助内容加载失败时，页面显示「帮助内容暂时不可用」，但仍保留 App 名称、
版本号和诊断信息。反馈失败时提示稍后重试。

## 移动端排版注意点

分组标题使用小号但清晰的字重。条目标题优先一行展示，说明文字最多两行。
关于信息放在页面底部，使用弱层级，不占据首屏核心空间。
