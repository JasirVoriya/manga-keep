# 首次使用引导页 UI 设计

本文档描述「漫集」首次使用引导页的 UI 设计。该页面用于帮助新用户理解
产品边界和核心使用方式。本文只描述页面自身排版和状态，不描述页面跳转。

## 页面目标

首次使用引导页必须在两到三步内说明「漫集」是什么、能做什么，以及用户如何
开始记录收藏。引导不能把用户挡在复杂设置前，也不能做成营销页。

## 整体布局

引导采用分页结构，每屏聚焦一个概念。页面像一本收藏册的扉页：背景温暖、
插图克制、文案短。

建议包含三屏：

1. 记录实体漫画收藏。
2. 看清缺本和想要。
3. 本地记录，可备份带走。

## 顶部区域

顶部显示品牌名「漫集」和英文名 `MangaKeep`。右上角放「跳过」，使用低调
文字按钮，但点击区域必须足够大。

顶部不放权限请求，也不要求用户先选择目录或登录。

## 主要内容区

每屏包含：

- 一个主标题。
- 一段短说明。
- 一个小型场景图或示意图。

第一屏强调漫画杂志、单行本、画集和特刊都可归档。第二屏强调已有、缺本和
想要。第三屏强调离线可信和备份迁移。

插图风格延续暖纸色和收藏册气质，不使用过度活泼或泛娱乐视觉。

## 底部操作区

底部显示分页点和主按钮。前几屏主按钮为「继续」，最后一屏为「开始记录」。
次级操作为「稍后再说」或「跳过」。

按钮区域固定在安全区上方，避免小屏设备上被系统手势遮挡。

## 状态呈现

当前分页点使用书架棕强调，未选分页点使用浅线色。最后一屏可以展示一条轻量
说明，例如「不用登录，也可以先记录本机收藏」。

## 空状态和错误状态

首次引导本身不需要复杂错误状态。如果默认目录暂时不可用，引导最后一屏以
轻提示说明「公共目录稍后可刷新」，但不阻止用户进入 App。

## 移动端排版注意点

主标题最多两行。说明文字不超过三行。插图不能挤压底部按钮。小屏设备上，
内容区可以减少插图高度，保证主按钮始终可见。
