# 导入预览与冲突处理页 UI 设计

本文档描述「漫集」导入预览与冲突处理页的 UI 设计。该页面用于在导入前让
用户确认新增、更新、跳过和冲突的数据。本文只描述页面自身排版和状态，不
描述页面跳转。

## 页面目标

导入预览与冲突处理页必须防止误覆盖。用户需要在真正写入前看清导入文件会
改变什么，以及冲突数据如何处理。

## 整体布局

页面采用“文件摘要、影响摘要、处理策略、预览列表、确认操作”的结构。信息
密度可以略高，但必须分层清楚。

## 顶部区域

顶部显示标题「导入预览」。标题下方展示文件摘要：

- 文件名。
- 导入类型。
- 文件创建时间。
- 数据来源。

再下方展示影响摘要：

- 新增数量。
- 更新数量。
- 跳过数量。
- 冲突数量。

冲突数量使用更明显的颜色，但不制造恐慌。

## 主要内容区

处理策略区提供批量策略选择：

- 保留现有数据。
- 使用导入数据。
- 只导入新增。
- 手动处理冲突。

默认策略必须偏安全，优先保留现有数据或只导入新增。

筛选标签用于切换预览列表：

- 全部。
- 新增。
- 更新。
- 冲突。
- 将跳过。

每个标签显示数量。预览列表项包含标题或目录名称、数据类型、当前状态和关键
差异摘要。

冲突项采用上下对比结构，分别展示现有数据和导入数据。差异字段包括标题、
编号、备注、收藏状态或目录定义。单项操作包含保留现有、使用导入、合并信息
和跳过。合并信息只在可合并时展示。

## 底部操作区

底部固定确认条显示本次将新增和更新的数量。主按钮为「确认导入」，次级操作
为「取消」。

仍有未处理冲突时，主按钮禁用或文案变为「处理冲突后导入」。覆盖现有数据
前必须出现最终确认，明确说明覆盖数量。

## 状态呈现

解析中显示文件解析进度。没有冲突时，摘要区显示「没有冲突，可直接导入」。
导入中锁定操作，显示进度和当前处理类型。导入完成后展示成功、跳过和失败
数量。

## 空状态和错误状态

没有可导入内容时，页面显示「没有可导入的数据」，并说明文件内容可能已存在
或不包含支持的数据。

文件解析失败时，显示失败原因和重新选择文件操作。部分导入失败时，展示失败
列表，并允许重试失败项或导出失败报告。

## 移动端排版注意点

影响摘要使用两列或四宫格，避免横向拥挤。冲突对比不能使用左右双栏，窄屏
下必须上下排列。列表项默认只展示关键差异，详细字段通过展开查看。底部确认
条始终露出影响数量。
