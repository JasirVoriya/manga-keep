# 批量与范围标记页 UI 设计

本文档描述「漫集」批量与范围标记页的 UI 设计。该页面用于一次性处理多个
条目的收藏状态，尤其适合按连续编号补录已有、缺本或想要。本文只描述页面
自身排版和状态，不描述页面跳转。

## 页面目标

批量与范围标记页必须让用户放心地处理大量条目。页面需要清楚表达操作范围、
目标状态和影响数量，避免用户误改大量收藏记录。

## 整体布局

页面采用“设置范围、选择状态、预览影响、确认执行”的纵向结构：

1. 顶部显示当前批量操作对象。
2. 中部提供范围输入和快捷范围。
3. 下方展示影响预览。
4. 底部固定确认栏。

页面不做复杂教程，依靠清晰控件和确认信息降低理解成本。

## 顶部区域

顶部显示标题「批量标记」和当前目录名称。标题下方展示简短统计，例如
「已有 120 · 缺本 18 · 想要 9」。

如果批量操作来自当前筛选结果，顶部可以显示筛选摘要，例如「当前筛选：
缺本」。摘要必须短，不占据过多首屏空间。

## 主要内容区

范围设置区包含起始编号和结束编号输入。输入框标签为「从」和「到」，支持
数字键盘。对于卷号或复合编号，输入框允许用户输入目录支持的编号格式。

快捷范围使用紧凑按钮组：

- 当前筛选结果。
- 当前搜索结果。
- 未标记条目。
- 缺本条目。

目标状态区使用三段式控件：

- 标为已有。
- 标为缺本。
- 标为想要。

高级选项以开关或复选框呈现，例如「覆盖已有状态」和「仅标记未设置状态」。
覆盖类选项必须靠近影响预览展示风险提示。

预览区展示将被影响的条目数量和列表。列表项包含编号、标题、当前状态和
更新后状态。状态变化使用文字表达，例如「缺本 -> 已有」。列表可以使用
紧凑行，不以封面为主。

## 底部操作区

底部固定确认栏展示影响数量，例如「将更新 24 项」。主按钮为「确认标记」，
次级操作为「取消」。

如果影响数量为 0，确认按钮禁用。如果将覆盖已有状态，确认栏展示明确提示，
例如「将覆盖 8 条已有记录」。

## 状态呈现

批量页的状态重点是操作前后对比。当前状态使用低饱和标签，目标状态使用
更明确的强调标签。覆盖风险使用玫红或深红棕提示，但不铺满页面。

不可更新条目用灰色显示，并在行内说明原因，例如「编号不在目录中」。

## 空状态和错误状态

范围无匹配时，预览区显示「该范围内没有条目」。当前筛选为空时显示
「当前筛选结果为空」。

编号格式错误时，在输入框下方显示「请输入有效编号」。起始编号大于结束
编号时显示「起始编号不能大于结束编号」。

批量保存失败时，保留当前设置和预览，底部提示「批量标记失败，请重试」。
部分成功时，显示成功和失败数量，并允许展开失败项。

## 移动端排版注意点

范围输入框在窄屏下上下排列，避免左右挤压。预览列表可滚动，底部确认栏
始终可见。危险提示要靠近确认按钮，而不是藏在页面顶部。
