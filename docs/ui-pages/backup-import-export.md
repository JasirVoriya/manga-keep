# 导入导出与备份页 UI 设计

本文档描述「漫集」导入导出与备份页的 UI 设计。该页面用于处理收藏记录、
本地目录定义和完整备份的导出与导入。本文只描述页面自身排版和状态，不描述
页面跳转。

## 页面目标

导入导出与备份页必须让用户清楚知道每个操作影响哪些数据。页面需要让备份
迁移变成普通用户能理解的操作，而不是开发者工具。

## 整体布局

页面按任务分组，而不是按文件格式分组：

1. 数据摘要。
2. 导出。
3. 导入。
4. 恢复与清理。

普通操作和危险操作必须有明显视觉隔离。

## 顶部区域

顶部显示标题「导入导出与备份」。标题下方显示数据摘要：

- 收藏记录数量。
- 本地目录数量。
- 最近一次导出时间。
- 最近一次导入时间。

摘要使用两列小指标。没有导出或导入记录时，用「尚未导出」或「尚未导入」
表达，不显示空白。

## 主要内容区

导出分组提供三个操作项：

- 导出收藏记录。
- 导出本地目录定义。
- 导出完整备份。

每个操作项包含简短说明、推荐场景和具体按钮。完整备份视觉权重最高，但
文案必须说明它包含收藏记录和本地目录定义。

导入分组提供：

- 导入目录定义。
- 导入完整备份。

导入项说明文件会先进入预览，不会立即覆盖现有数据。

恢复与清理分组放在页面底部，包含清空类或覆盖类操作。该分组使用更明确的
边界和警示色，但不使用大面积红色背景。

## 底部操作区

页面默认不需要全局固定按钮。每个任务项内有自己的操作按钮。

当用户已经选择文件但尚未预览时，底部可以出现临时文件条，展示文件名、文件
大小、「继续预览」和「取消」。文件名过长时中间截断，保留扩展名。

## 状态呈现

导出中时，对应项显示「准备文件中」。导出成功后显示文件名，并提供保存或
分享入口。

导入文件读取中时，页面显示解析状态。文件可用时展示文件摘要和继续预览按钮。

危险操作待确认时，使用确认面板说明影响范围。

## 空状态和错误状态

没有备份记录时，数据摘要推荐「导出完整备份」。

文件格式错误时，显示「文件无法识别」，并说明支持的导入类型。导出失败时，
说明可能原因，例如存储权限、空间不足或文件创建失败，并提供重试。

## 移动端排版注意点

每个操作项的说明控制在两行内。按钮文案必须具体，避免只写「导入」或
「导出」。危险区与普通操作区需要有足够间距，避免误触。
