# 目录中心页 UI 设计

本文档描述「漫集」目录中心页的 UI 设计。该页面用于集中展示内置目录、
公共目录和本地目录的可用状态，并承载目录刷新、创建和导入等管理动作。
本文只描述页面自身排版和状态，不描述页面跳转。

## 页面目标

目录中心页必须让用户理解当前有哪些目录可用，以及每类目录来自哪里。页面
需要让官方目录保持开箱可用，同时让本地目录和导入目录成为可发现的扩展能力。

## 整体布局

页面采用移动端纵向信息流，背景为暖纸色。内容层级从上到下为：

1. 目录状态摘要。
2. 官方与公共目录。
3. 本地目录。
4. 目录工具。

页面避免把目录管理做成后台表格。每组信息使用轻量分区和紧凑列表。

## 顶部区域

顶部显示标题「目录中心」。标题下方显示说明文案，例如「管理用于识别和补全
实体出版物的目录」。

状态摘要区展示：

- 当前启用目录数量。
- 公共目录最近更新时间。
- 本地目录数量。
- 是否存在刷新失败或待处理导入。

右侧可放刷新图标按钮。刷新中按钮显示小型加载状态，不阻塞页面浏览。

## 主要内容区

官方与公共目录分组展示官方维护的目录。每个目录项包含：

- 目录名称。
- 覆盖类型，例如杂志、单行本、画集或特刊。
- 条目数量。
- 更新时间。
- 状态标签，例如已启用、可更新或刷新失败。

本地目录分组展示用户创建或导入的目录。每个目录项包含：

- 目录名称。
- 条目数量。
- 最近编辑时间。
- 来源说明。
- 是否启用。

目录工具分组提供小型操作入口：

- 新建本地目录。
- 导入目录定义。
- 查看目录数据占用。
- 查看目录刷新状态。

危险操作不直接暴露在列表主层级。

## 底部操作区

底部可以固定主操作「新建本地目录」。次级操作「导入目录定义」使用描边按钮。
如果内容较长，底部操作区必须避开列表最后一项。

## 状态呈现

刷新中时，公共目录区域显示内联进度。可更新状态使用橙色提示，刷新失败使用
低饱和玫红提示。已禁用目录降低视觉权重，但仍保持可读。

目录来源需要清楚标记为内置、公共或本地，避免用户误以为所有目录都来自网络。

## 空状态和错误状态

没有本地目录时，本地目录分组显示「还没有本地目录」，并提供新建和导入入口。

公共目录加载失败时，页面显示非阻塞错误区「公共目录暂时无法刷新」，保留
重试按钮，并继续展示内置目录和本地目录。

## 移动端排版注意点

目录名称最多两行，元信息用单行分隔点展示。列表项高度保持可扫读，不写长
说明。主操作区最多一个主按钮和一个次按钮，避免页面像控制台。
