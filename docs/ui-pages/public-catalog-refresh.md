# 公共目录刷新状态页 UI 设计

本文档描述「漫集」公共目录刷新状态页的 UI 设计。该页面用于展示公共目录
版本、刷新状态和本地可用性。本文只描述页面自身排版和状态，不描述页面跳转。

## 页面目标

公共目录刷新状态页必须建立用户信任：公共目录可以更新，但本地收藏不会因为
网络或刷新失败而不可用。

## 整体布局

页面采用设置型工具页。上半部分展示当前状态，下半部分展示刷新内容和最近
记录。视觉上安静、清晰，不做活动页或宣传页。

## 顶部区域

顶部标题为「公共目录」。标题下方显示状态摘要，例如「已是最新」「可刷新」
或「暂时无法检查」。

右侧放手动刷新按钮。刷新中按钮切换为加载状态，避免重复触发。

## 主要内容区

状态信息包含：

- 当前目录版本或更新时间。
- 公共目录数量。
- 条目数量。
- 本地收藏是否可用。
- 最近刷新结果。

刷新中展示步骤文本，例如「正在检查版本」「正在下载目录」「正在更新索引」。
刷新内容摘要展示本次新增、更新或修正的目录数量。

下方可以展示最近 3 条刷新记录。技术细节如源地址和版本号使用小号文字，但
不能过淡。

## 底部操作区

底部或内容末尾提供主按钮「刷新目录」。刷新失败时主按钮变为「重试」。次级
操作可以是「查看说明」。

按钮区不需要常驻复杂操作，重点是让用户知道刷新不会影响本地记录。

## 状态呈现

状态包含：

- 已是最新。
- 可更新。
- 刷新中。
- 刷新成功。
- 刷新失败。
- 离线不可检查。

本地可用状态必须单独呈现，例如「本地收藏可正常使用」。这条信息在失败状态
下仍然可见。

## 空状态和错误状态

首次没有公共目录时，页面显示「暂无公共目录，本地收藏仍可记录」。

刷新失败时显示失败原因类别，例如网络不可用、下载中断或目录校验失败，并
提供重试。失败状态不使用整页红色警告。

## 移动端排版注意点

状态摘要必须在首屏可见。刷新日志最多展示最近 3 条，避免页面像调试面板。
版本号和更新时间可小字号展示，但需要满足可读性。
